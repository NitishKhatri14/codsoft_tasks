# Frontend Development Projects

A collection of five responsive web development projects built using HTML, CSS, and JavaScript.

## Projects

### 1. Personal Portfolio Website
A responsive portfolio showcasing a professional profile, skills, projects, resume, and contact form.

### 2. To-Do List Application
A task management application featuring task creation, editing, deletion, completion tracking, search, filters, and Local Storage.

### 3. Expense Tracker
A personal finance application for tracking income, expenses, transactions, and current balance, with category filters and dark mode.

### 4. Music Player
A web-based music player with playback controls, a progress bar, volume adjustment, playlists, shuffle, repeat, and favorites.

### 5. Blog Website
A responsive blog platform with featured articles, categories, tags, search, article details, pagination, dark mode, comments, and social sharing.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Responsive Web Design

## How to Run

1. Clone or download this repository.
2. Open the required project folder.
3. Open its `index.html` file using a browser or VS Code Live Server.
4. Follow any project-specific instructions for uploading assets or using local files.
